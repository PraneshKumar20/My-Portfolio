A modern, highly interactive personal portfolio built with **React**, **Three.js**, **GSAP**, and **Tailwind CSS**. Designed with rich aesthetics, fluid 3D interactions, dynamic spotlight effects, and smooth page transitions.

🌐 **Live URL:** [https://my-portfolio-psi-six-23.vercel.app/](https://my-portfolio-psi-six-23.vercel.app/)

---

## ✨ Highlights & Features

- **Interactive 3D Stage**: Custom Three.js geometric visualizer and interactive portrait decoding.
- **Micro-Interactions**: Dynamic cursor-tracking spotlight glow on project cards and 3D perspective tilt.
- **Smooth Animations**: GSAP ScrollTrigger timeline reveals, smooth scroll physics, and confetti appreciation.
- **Curated Projects**:
  - **Hairloon**: Salon discovery and AI hairstyle recommendation platform.
  - **Expense Tracker**: MERN stack personal finance workspace with real-time analytics.
- **LeetCode & Certifications Showcase**: Interactive modal breakdown of 300+ DSA problems and verified credentials.
- **Responsive & Accessible**: Optimized for all devices, dark/light theme toggle, and reduced motion support.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS v4
- **3D & Graphics**: Three.js, Canvas Confetti
- **Animation Engine**: GSAP (ScrollTrigger), Motion
- **Icons**: Lucide React
- **Deployment**: Vercel

## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/PraneshKumar20/My-Portfolio.git
   cd My-Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
